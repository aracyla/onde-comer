# css-dev

Plain CSS development workflows using the `*.module.css` convention.

## Skills

| Skill | Purpose |
|---|---|
| `css-dev:router` | Entry point. Detects intent and routes to a sub-skill. Holds the canonical CSS patterns. |
| `css-dev:create-component` | Create new CSS components. |
| `css-dev:validate` | Audit existing CSS against the patterns. |

## Commands

- `/css-dev [request]` - starts the router.
