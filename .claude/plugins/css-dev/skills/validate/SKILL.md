# CSS Development: Validate

## Overview

**This is a sub-skill of `css-dev`** (invoked via `css-dev:router`) - typically invoked automatically via the main skill.

## When This Skill Applies

Use when:
- Reviewing existing CSS code
- Auditing component styles for consistency
- Checking if patterns are being followed
- Before merging CSS changes
- Refactoring prep (identify issues first)

See the `css-dev:router` skill for the canonical pattern reference (semantic naming, dark mode, composition, testing).
