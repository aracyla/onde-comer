# js-dev

Basic JavaScript development workflows with a routing structure.

## Skills

| Skill | Purpose |
|---|---|
| `js-dev:router` | Entry point. Detects intent, holds the shared JS standards, routes to a sub-skill. |
| `js-dev:code` | General coding guidelines for writing JavaScript. |
| `js-dev:validate` | How to review and validate written JavaScript. |
| `js-dev:test` | How to create and run tests. |

## Commands

- `/js-dev [request]` - starts the router.

## Status

Starter standards only. Refine each skill as real problems come up.
